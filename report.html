Report a Bug

Help us improve moment·e by reporting issues you encounter.

Bug reports go to GitHub Issues Our issue tracker is public — you can submit and view reports without creating a code account. A GitHub account is required to submit.

Before You Submit

To avoid duplicate reports, please:

  • Check the existing issues list to see if it's already reported
  • Make sure you're on the latest version of the app (v13.04)
  • Try restarting the app to see if the issue persists

How to Submit

1

Open the issue tracker

Go to github.com/nader938/moment_e_issues and click New Issue.

2

Sign in to GitHub

A free GitHub account is required. You can create one at github.com/join — it takes under a minute.

3

Fill in the details

Give your issue a clear title and include the information listed below.

4

Submit

Click Submit new issue. The research team will be notified and will respond as soon as possible.

What to Include

Good bug reports help us fix issues faster. Please include:

  • Platform — iOS or Android
  • Device & OS version — e.g. iPhone 14, iOS 17.4 or Samsung S23, Android 14
  • App version — shown on the splash screen as vXX.XX (currently v13.04)
  • What you were doing — which screen or task you were on
  • What happened — describe the unexpected behavior or error message
  • What you expected — what should have happened instead
  • Steps to reproduce — numbered steps to reliably trigger the issue
Do not include personal data Please do not include your name, participant ID, study data, or any health information in bug reports. Issues are publicly visible.

Check Existing Issues

Before submitting, browse open and closed issues — your problem may already be known or fixed.
