# Report a Bug

Help us improve moment·e by reporting issues you encounter. **No account needed.**

## How to Submit

[**→ Submit a bug report**](https://docs.google.com/forms/d/e/1FAIpQLSfUAUD10cVaCMcNK4VQwKyEfvDebiOW4lkqdZyl7EmqHPOGqw/viewform) — opens a short form, takes about 2 minutes.

If the link above isn't working, email us directly: [naderami@gmail.com](mailto:naderami@gmail.com?subject=moment%C2%B7e%20bug%20report)

## What We'll Ask

| Field | Example |
|---|---|
| **Platform** | iOS or Android |
| **Device & OS** | iPhone 14, iOS 17.4 |
| **App version** | v13.04 (shown at the bottom of the Profile screen) |
| **What you were doing** | Which screen or task |
| **What happened** | Describe the bug or error |
| **Expected behavior** | What should have happened |
| **Steps to reproduce** | Numbered steps to trigger the issue |

:::danger Do not include personal data
Please do not include your name, participant ID, study data, or any health information in bug reports.
:::

## Before You Submit

- Make sure you're on the latest version (**v13.04**)
- Try restarting the app to see if the issue persists
