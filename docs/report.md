# Report a Bug

Help us improve moment·e by reporting issues you encounter.

:::info Bug reports go to GitHub Issues
Our issue tracker is public — you can submit and view reports without needing access to the source code. A free GitHub account is required to submit.
:::

## Before You Submit

- Check [existing issues](https://github.com/nader938/moment_e_issues/issues) to see if it's already reported
- Make sure you're on the latest version (**v13.04**)
- Try restarting the app to see if the issue persists

## How to Submit

1. Go to [github.com/nader938/moment_e_issues/issues/new](https://github.com/nader938/moment_e_issues/issues/new) and click **New Issue**
2. Sign in to GitHub (free account — takes under a minute at [github.com/join](https://github.com/join))
3. Fill in the details below
4. Click **Submit new issue** — the team is notified and will respond as soon as possible

## What to Include

| Field | Example |
|---|---|
| **Platform** | iOS or Android |
| **Device & OS** | iPhone 14, iOS 17.4 |
| **App version** | v13.04 (shown on splash screen) |
| **What you were doing** | Which screen or task |
| **What happened** | Describe the bug or error |
| **Expected behavior** | What should have happened |
| **Steps to reproduce** | Numbered steps to trigger the issue |

:::danger Do not include personal data
Please do not include your name, participant ID, study data, or any health information in bug reports. Issues are publicly visible.
:::
